# Base Camp - Data Fusion Dashboard

A modern, real-time data fusion and analytics dashboard built with Next.js 14, React, and TailwindCSS.

## Features

- Real-time data monitoring and visualization
- Multiple data source integration (IoT, databases, APIs)
- Customizable dashboard with responsive design
- Alert management and notifications
- Analytics and reporting capabilities
- Model management for ML pipelines

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI**: React 18, TailwindCSS
- **State Management**: TanStack Query (React Query)
- **Language**: TypeScript
- **Styling**: CSS Variables with Tailwind

## Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm, yarn, or pnpm

### Installation

1. Navigate to the frontend directory: cd frontend
2. Install dependencies: npm install
3. Start the development server: npm run dev
4. Open http://localhost:3000 in your browser.

## Available Scripts

- npm run dev: Start development server
- npm run build: Build for production
- npm run start: Start production server
- npm run lint: Run ESLint
